# Meta_Ad_performance_Analysis
Meta Ad Performance Dashboard analyzes Facebook and Instagram campaigns to track impressions, clicks, engagement, and conversions. It identifies top audiences, ad formats, and trends, helping optimize targeting, budget allocation, and ROI through interactive Power BI visualizations and data-driven insights.
Meta Ad Performance Dashboard
# Project Overview
This project analyzes advertising performance data from Meta platforms (Facebook and Instagram) to evaluate campaign effectiveness, audience engagement, and conversion performance. The goal is to track key marketing metrics such as impressions, clicks, engagements, and purchases using an interactive dashboard.
The dashboard provides insights into customer behavior, ad effectiveness, and budget utilization, helping improve targeting strategies, campaign performance, and return on investment (ROI).

# Key Performance Indicators (KPIs) / Business Questions
The dashboard is designed to answer the following key business questions:
1. What is the total number of impressions, clicks, and engagements?
2.  What is the total number of purchases (conversions)?
3.  What are the CTR, engagement rate, and conversion rate?
4.  Which audience segments (age, gender) engage the most?
5.  Which countries contribute the most to ad performance?
6.  Which ad types (Video, Stories, Image, Carousel) perform best?
7.  How does engagement vary over time (weekly and hourly)?
8.  How efficiently is the advertising budget utilized?

# Process
The analysis was performed on Meta Ads data using the following steps:
1. Cleaned and prepared the dataset by handling missing values and formatting data
2.  Built relationships between tables (ad_events, ads, campaigns, users)
3.  Created calculated fields such as CTR, engagement rate, conversion rate, and purchase rate
4.  Performed exploratory data analysis to identify patterns in engagement and conversions
5.  Built interactive visualizations using Power BI (charts, maps, KPI cards, slicers)
6.  Extracted insights to support marketing and business decision-making

# Key Insights
1. Ads generate strong reach and engagement, indicating effective top-of-funnel performance.
2.  CTR (~11.7%) and engagement rate (~13.5%) are significantly higher than industry averages.
3.  Conversion rate (~5.2%) is moderate, but purchase rate (~0.6%) is low, showing a drop in final conversions.
4.  Female users and the 18–30 age group contribute the highest engagement.
5.  Countries like the US, India, and Brazil generate the most activity.
6.  Video and Story ads perform better than Image and Carousel ads.
7.  Engagement peaks during afternoon and evening hours.

# Conclusion
The Meta Ad Performance Dashboard highlights strong campaign performance in terms of visibility and engagement but identifies a gap in conversion efficiency. The analysis suggests focusing on high-performing audience segments, optimizing ad formats, and improving the conversion funnel to increase overall ROI and campaign effectiveness.
